Chorus INF To Calc  (INF2Calc)

INF2Calc est une macro LibreOffice permettant l’ouverture dans Calc des restitutions Chorus INF exportées en Excel 2000 
après conversion automatique en fichier Excel (.xlsx) exploitable nativement par Calc sans perdre la mise en forme du tableau.
